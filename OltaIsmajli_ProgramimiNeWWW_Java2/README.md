# Pikënisja — Java II

## Hyrjet
Të dhënat tekstuale të tre sendeve të ekspozitës: çelësi, filxhani dhe bileta, si dhe ilustrimet SVG të dhëna në folder.

## Daljet
Një faqe web responsive që paraqet ekspozitën me navigim, tre karta, ilustrime dhe seksione "Historia e fshehur".

## Rast normal
Përdoruesi hap faqen dhe shikon të tre sendet, pastaj hap historinë e fshehur të njërit prej tyre.

## Rast kufitar 1
Faqja hapet në ekran të vogël; kartat kalojnë në një kolonë dhe përmbajtja mbetet e lexueshme.

## Rast kufitar 2
Përdoruesi navigon direkt te një kartë përmes lidhjeve të navigimit; faqja e çon te seksioni përkatës.
